Проверяю Node.js и MySQL…

Если сервер ещё не живой — файлы лежат в public_html, но Node.js не запущен, а база не подключена.

  1. Панель Beget → MySQL → база ironwake (получится biker9td_ironwake).
  2. phpMyAdmin → Импорт → файл sql/001_schema.sql.
  3. Скопируйте config.local.json.example в config.local.json и впишите пароль базы.
  4. SSH: npm install, затем включите Passenger в .htaccess (см. README).
